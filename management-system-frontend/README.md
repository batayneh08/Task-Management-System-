# Angular frontend

مشروع Angular مستقل باستخدام standalone components وAngular Router. هذه نقطة بداية عامة ولا تفترض صفحات أو نماذج خاصة بالمجال.

## التشغيل

نفّذ `npm install` ثم `npm start` من هذا المجلد، وافتح `http://localhost:4200`.

## بنية البداية

- `src/main.ts` — نقطة تشغيل التطبيق.
- `src/app/app.config.ts` — إعداد Angular ومزودات التطبيق.
- `src/app/app.routes.ts` — مكان تعريف المسارات.
- `src/app/app.component.ts` و`app.component.html` — المكوّن الجذري.
- `src/styles.css` — الأنماط العامة.

أضف الصفحات والخدمات والنماذج عند تحديد احتياجات التطبيق.
